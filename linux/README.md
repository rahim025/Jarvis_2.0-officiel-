# J.A.R.V.I.S — Assistant IA Personnel (Linux)

> Version Linux du projet JARVIS par Rahim Batchabi

## Prérequis
- Ubuntu 22.04+, Debian 12+ ou Linux Mint 21+
- Python 3.10+
- Une clé API Gemini (obligatoire)

## Installation
```bash
cd LINUX
bash install_linux.sh
cp .env.example .env   # puis ajoute tes clés
./start_jarvis.sh
```
